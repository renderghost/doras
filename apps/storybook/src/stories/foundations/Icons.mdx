# Icons

Doras uses [Lucide](https://lucide.dev) icons, at 16, 20, 24 or 32px (`size.icon.*`), in the icon colours. These are the icons the Front Door prototype uses. The Icon component arrives in [#10](https://github.com/renderghost/doras/issues/10).

- **Decorative by default:** an icon next to words is hidden from screen readers.
- **Named when it carries meaning:** an icon on its own gets an accessible name.
- **Mirrored when it points a direction:** in right-to-left layouts, arrows flip. Icons that don't point a direction never do.
