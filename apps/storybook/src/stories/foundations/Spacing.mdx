# Spacing and size

Lengths are written in px and become rem on the web, so layouts grow with text size. Border widths and the focus ring stay in px. iOS uses the same numbers as points, and Android as dp.

## Spacing

- **Inset:** padding inside a container.
- **Stack:** space between things above and below each other.
- **Inline:** space between things side by side.
