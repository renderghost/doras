# Contributing

How components are documented, and the checklist each one meets, are in [CONTRIBUTING.md](https://github.com/renderghost/doras/blob/main/CONTRIBUTING.md).

## Docs pages

Every component's docs page is generated from its spec, with the same sections in the same order:

1. Overview
2. When to use it, and when not to
3. Anatomy
4. States
5. Props and events, including measurement events
6. Accessibility: keyboard, screen readers and ARIA
7. Tokens
8. Content: guidelines, strings and words it uses
9. Do and don't
10. Evidence and decisions

Every docs page is generated from the component's spec in `@doras/specs`, set on its stories as `parameters.doras.spec`. Controls come from the spec's props too, with `argTypesFromSpec`. The Actions components are the first examples: start with **Actions → Button**.
