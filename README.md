# Doras

Doras (Irish for "door") is the design system for creating an Atmosphere account and signing in with one: design tokens, Web Components, flows and emails, documented in Storybook.

It grows out of the Front Door prototype at [renderghost/at-frontdoor](https://github.com/renderghost/at-frontdoor). The plan and every decision behind it are in the epic, [#1](https://github.com/renderghost/doras/issues/1).
