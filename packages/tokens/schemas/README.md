# DTCG 2025.10 JSON Schemas

Unchanged copies of the official Design Tokens Community Group schemas, used by the tests to validate every token file and the resolver document offline:

- `format.json`, from https://www.designtokens.org/schemas/2025.10/format.json
- `resolver.json`, from https://www.designtokens.org/schemas/2025.10/resolver.json

Each bundles the sub-schemas it references. Don't edit or reformat them: download them again to update.
