# Provider logos

Each provider's logo goes here as its own file, and is listed in `../providers.ts` with:

- `src`: the file.
- `source`: where it came from, such as the provider's press kit.
- `permission`: who agreed to its use, and when.

No logos are here yet: none has a recorded permission. Until one does, the provider's badge shows a plain tile with its initial. If a provider asks, remove its file and set its `logo` to `null`.
